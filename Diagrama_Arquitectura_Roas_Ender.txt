Usuarios (users)
GET /api/users — Listar usuarios
GET /api/users/:id — Obtener usuario por ID
POST /api/users — Crear usuario
PUT /api/users/:id — Actualizar usuario
DELETE /api/users/:id — Eliminar usuario
Guías (guides)
GET /api/guides — Listar guías
GET /api/guides/:id — Obtener guía por ID
POST /api/guides — Crear guía
PUT /api/guides/:id — Actualizar guía
DELETE /api/guides/:id — Eliminar guía
Reservas (bookings)
GET /api/bookings — Listar reservas
GET /api/bookings/:id — Obtener reserva por ID
POST /api/bookings — Crear reserva
PUT /api/bookings/:id — Actualizar reserva
DELETE /api/bookings/:id — Eliminar reserva

DELETE /api/zones/:id

Relaciones (ejemplo)
GET /api/guides/:id/specialties — Especialidades de un guía
GET /api/guides/:id/languages — Idiomas de un guía
GET /api/users/:id/bookings — Reservas de un usuario

Flujo de implementación:
Modelos y Repositorios

Crear modelos y esquemas para cada entidad (MongoDB para users, PostgreSQL para guides, bookings, zones, etc.).
Implementar repositorios (Repository Pattern) para acceso a datos.
Servicios y Controladores

Crear servicios (Service Layer) para lógica de negocio.
Implementar controladores para cada endpoint RESTful.
Rutas y Middlewares

Adaptar rutas para usar controladores persistentes.
Proteger con JWT y validar datos.
Relaciones y Consultas Avanzadas

Implementar endpoints de relaciones (ej: /guides/:id/specialties).
Consultas JOIN y agregaciones según el diagrama.
Pruebas y Validación

Probar todos los endpoints con datos reales.
Ajustar validaciones, errores y respuestas.
Documentación y Ajustes Finales

Actualizar Swagger/OpenAPI.
Dejar todo listo para integración frontend/mobile.
