FLUJO DE REPLICACIÓN (ETL)

Postgres (tablas relacionales)
    |
    |  scripts/replicate-to-mongo.js  (servicio ETL)
    |   - Conecta a Postgres usando POSTGRES_URL
    |   - Conecta a MongoDB usando MONGODB_URI
    |   - Detecta columnas dinámicamente (information_schema)
    |   - Normaliza filas y hace bulkWrite (upsert) en Mongo
    |   - Registra errores en colección `replication_errors`
    v
+----------------------------------------------------------------------------------------+
|                             MongoDB (DataMart / Analítica)                            |
|  Colecciones típicas (replicadas desde Postgres):                                      |
|    - hospedajes  (documentos upsertados desde postgres.hospedajes)                     |
|    - alimentacion_options (desde postgres.alimentacion_options)                        |
|    - replication_errors (logs de errores del ETL)                                      |
+----------------------------------------------------------------------------------------+

NOTAS DE INTEGRIDAD Y FK
- hospedajes.zone_id -> zones.id (índice recomendado)
- hospedajes.guide_id -> guides.id (índice recomendado)
- alimentacion_options.hospedaje_id -> hospedajes.id (índice recomendado)
- El ETL corre como servicio `etl` dentro del docker-compose y debe tener acceso a la red compose

PUERTO Y EJECUCIÓN
- Puerto por defecto: 3000 (dev). En producción: 4000 si no se pasa PORT.
  Código: `src/api/server.ts` (PORT = process.env.PORT ?? (NODE_ENV==='production' ? 4000 : 3000)).
- Para ver Swagger desde el navegador en tu máquina local con docker-compose, debes exponer el puerto 4000 del servicio API al host o usar un contenedor temporal que mapee ese puerto.

SUGERENCIA: ACTUALIZAR `docker-compose.yml` para agregar un servicio `api` (o exponer puerto del `web` o `etl` según corresponda) y mapear `4000:4000` para que puedas abrir http://localhost:4000/api-docs desde tu browser.

EJEMPLO (sugerido) — fragmento para añadir a `docker-compose.yml`:

  api:
    build:
      context: .
      dockerfile: Dockerfile.api
    image: road_ender-api
    environment:
      - POSTGRES_URL=${POSTGRES_URL}
      - MONGODB_URI=${MONGODB_URI}
      - PORT=4000
    ports:
      - "4000:4000"
    depends_on:
      - postgres
      - mongodb
    networks:
      - tourist-guides-network

(Con esto el endpoint /api-docs quedará accesible en http://localhost:4000/api-docs )
